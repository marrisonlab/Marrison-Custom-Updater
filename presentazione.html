Marrison Custom Updater

Sistema di gestione aggiornamenti per plugin e temi WordPress privati

Descrizione Generale

Marrison Custom Updater è un plugin WordPress che estende le funzionalità native di aggiornamento, permettendo di gestire plugin e temi provenienti da repository personalizzati esterni alla directory ufficiale di WordPress.org. Il plugin si integra completamente con l'interfaccia di amministrazione WordPress, offrendo un'esperienza utente coerente con quella dei plugin ufficiali.

Funzionalità Principali

  • Repository Privato — Connessione a repository personalizzati per ricevere aggiornamenti di plugin e temi proprietari non distribuiti tramite WordPress.org.
  • Gestione Unificata — Visualizzazione e installazione degli aggiornamenti per plugin e temi privati direttamente dalla dashboard WordPress, con la stessa interfaccia dei plugin ufficiali.
  • Backup Integrato — Creazione automatica di backup prima di ogni aggiornamento per tutti i plugin e temi, con possibilità di ripristino rapido (rollback).
  • Aggiornamenti Automatici — Programmazione di aggiornamenti automatici con frequenza giornaliera o settimanale, con report email dettagliati.
  • Esclusioni — Possibilità di escludere specifici plugin dagli aggiornamenti automatici, mantenendo il controllo su quali estensioni aggiornare.
  • Gestione Traduzioni — Strumento dedicato per aggiornare le traduzioni dei plugin e temi, garantendo il supporto multilingua sempre aggiornato.
  • Pulizia Backup — Rimozione automatica dei backup dei plugin non più installati, mantenendo la cartella di backup organizzata.
  • Log e Monitoraggio — Sistema di logging integrato per tracciare tutte le operazioni di aggiornamento e i cron job, facilitando il debug.

Modalità di Funzionamento

Configurazione Repository

Il plugin permette di configurare uno o più repository personalizzati tramite l'interfaccia delle impostazioni. L'amministratore inserisce l'URL del repository (che deve fornire un file JSON con i metadati degli aggiornamenti disponibili) e il sistema verifica periodicamente la disponibilità di nuove versioni. È possibile configurare separatamente repository per plugin e per temi, permettendo una gestione flessibile delle diverse tipologie di estensioni.

Sistema di Backup e Ripristino

Prima di ogni operazione di aggiornamento, il plugin crea automaticamente un backup dell'estensione interessata. Il backup include tutti i file del plugin o tema nella versione attualmente installata, compressi in formato ZIP e salvati in una cartella dedicata.

Il sistema di backup copre:

  • Plugin privati provenienti da repository personalizzati
  • Plugin pubblici scaricati da WordPress.org
  • Plugin costituiti da un singolo file PHP
  • Plugin organizzati in cartelle con struttura complessa
  • Temi privati e temi pubblici

In caso di problemi dopo un aggiornamento, è possibile ripristinare qualsiasi versione precedentemente backuppata con un singolo clic. Il ripristino riporta il plugin o tema allo stato precedente e, se necessario, riattiva l'estensione.

Il plugin include anche una funzione di pulizia automatica dei backup orfani: quando si accede alla sezione backup, il sistema verifica quali plugin sono ancora installati e rimuove i backup di quelli non più presenti, mantenendo la cartella di backup pulita.

Aggiornamenti Manuali

Gli aggiornamenti possono essere eseguiti manualmente tramite l'interfaccia di amministrazione. Il plugin mostra nella lista dei plugin e temi i badge di aggiornamento disponibili, con la possibilità di aggiornare singolarmente o in blocco.

La funzione "Aggiorna tutto" esegue in sequenza:

  • Aggiornamento di tutti i plugin privati
  • Aggiornamento dei plugin pubblici/ufficiali
  • Aggiornamento di tutti i temi
  • Aggiornamento delle traduzioni

Ogni operazione è preceduta dalla creazione di un backup automatico e seguita dalla pulizia della cache di WordPress per garantire che le nuove versioni siano correttamente riconosciute.

Aggiornamenti Automatici Programmati

Il plugin permette di configurare aggiornamenti automatici che vengono eseguiti tramite il sistema cron di WordPress. L'amministratore può scegliere tra frequenza giornaliera o settimanale e definire a quali indirizzi email inviare i report.

Al termine di ogni aggiornamento automatico, il sistema invia un'email dettagliata contenente:

  • Lista dei plugin aggiornati con indicazione delle versioni (precedente → nuova)
  • Dettagli degli errori eventualmente verificatisi, con codici di errore
  • Elenco dei plugin saltati e motivazione dell'esclusione
  • Stato dell'aggiornamento del database di Elementor (se presente e aggiornato)
  • Riepilogo dei plugin attivi e inattivi dopo l'aggiornamento

Il sistema verifica automaticamente i requisiti PHP dei plugin prima dell'aggiornamento e salta quelli che richiedono versioni di PHP non disponibili sul server, prevenendo errori di compatibilità.

Sistema di Esclusioni

Per garantire il controllo completo sulle estensioni aggiornate, il plugin offre un sistema di esclusioni. L'amministratore può marcare specifici plugin come "esclusi" dagli aggiornamenti automatici, mantenendoli alla versione corrente anche se sono disponibili aggiornamenti.

Le esclusioni funzionano per tutti i tipi di plugin:

  • Plugin privati provenienti dal repository personalizzato
  • Plugin pubblici da WordPress.org
  • Plugin premium con PluginURI personalizzato

I plugin esclusi vengono mostrati con un badge distintivo nell'interfaccia e vengono saltati sia dagli aggiornamenti automatici che dall'operazione "Aggiorna tutto". L'esclusione può essere rimossa in qualsiasi momento per ripristinare l'aggiornabilità del plugin.

Gestione Traduzioni

Il plugin include una sezione dedicata alla gestione delle traduzioni. Questa funzionalità permette di aggiornare i file di traduzione (.mo, .po) per tutti i plugin e temi installati, garantendo che le interfacce utente rimangano localizzate correttamente anche dopo gli aggiornamenti.

Il sistema verifica la disponibilità di nuove traduzioni e permette di aggiornarle singolarmente o in blocco, con feedback visivo sullo stato dell'operazione.

Logging e Debug

Per facilitare la risoluzione di problemi e il monitoraggio delle operazioni, il plugin mantiene un log dettagliato di tutte le attività. Il log registra:

  • Operazioni di aggiornamento eseguite (manuali e automatiche)
  • Risultati dei cron job programmati
  • Errori e avvisi verificatisi durante le operazioni
  • Timestamp di ogni operazione

Il log è accessibile dall'interfaccia di amministrazione e può essere utilizzato per diagnosticare problemi di aggiornamento o verificare che le operazioni programmate siano state eseguite correttamente.

Integrazione con WordPress

Il plugin si integra completamente con il sistema nativo di WordPress:

  • Utilizza il sistema di transients di WordPress per il caching delle informazioni sugli aggiornamenti
  • Si aggancia agli hook standard di WordPress per gli aggiornamenti (upgrader_process_complete)
  • Utilizza le API native di WordPress per le operazioni sul filesystem
  • Si integra con la pagina Plugins di WordPress per mostrare gli aggiornamenti disponibili
  • Utilizza il sistema cron di WordPress per le operazioni programmate

Requisiti di Sistema

  • WordPress versione 6.0 o superiore
  • PHP versione 7.4 o superiore
  • Accesso in scrittura alla cartella wp-content per le operazioni di backup
  • Estensione ZIP disponibile sul server per la compressione dei backup
  • Cron job di WordPress attivi per gli aggiornamenti automatici

Casi d'Uso Tipici

Sviluppatori di Plugin Privati

Per sviluppatori che distribuiscono plugin proprietari ai propri clienti senza pubblicarli su WordPress.org, il plugin offre un sistema centralizzato per distribuire aggiornamenti. I clienti ricevono notifiche di aggiornamento e possono installare le nuove versioni con la stessa facilità dei plugin ufficiali.

Agenzie Web

Le agenzie che gestiscono numerosi siti WordPress possono utilizzare il plugin per mantenere aggiornati i plugin e temi sviluppati internamente su tutti i siti dei clienti, con la possibilità di programmare aggiornamenti automatici e ricevere report via email.

Siti con Plugin Premium

Per siti che utilizzano plugin premium non disponibili su WordPress.org, il plugin permette di centralizzare la gestione degli aggiornamenti e di mantenere backup automatici prima di ogni installazione, riducendo il rischio di downtime causato da aggiornamenti problematici.
