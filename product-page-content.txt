PRODUCT PAGE CONTENT - MARRISON CUSTOM UPDATER
================================================

FEATURE SECTIONS
----------------

## Private Repository for Custom Plugins

Manage updates for hundreds of WordPress sites from a single, centralized private repository. Upload your custom or modified plugins to your own server and distribute updates to all your client sites automatically. The plugin integrates seamlessly with WordPress's native update system, so your clients can install updates with the same ease as official plugins from WordPress.org. Perfect for agencies, developers, and anyone managing multiple WordPress installations with proprietary extensions.

## Scheduled Updates with Email Reports

Automate your update workflow with flexible scheduling options. Configure daily or weekly automatic updates for plugins, themes, and translations, and receive detailed email reports after each run. The reports include updated items with version changes, any errors encountered, skipped plugins with reasons, and Elementor database update status. Keep your sites secure and up-to-date without manual intervention, while maintaining full visibility into every automated operation.

## Plugin Exclusion Control

Maintain complete control over which plugins get updated. Mark specific plugins as "excluded" from automatic updates to keep them at their current version, even when newer releases are available. This is essential for plugins that require testing before deployment, custom modifications that shouldn't be overwritten, or compatibility-critical extensions. Excluded plugins are clearly marked in the interface and respected by both scheduled updates and bulk update operations, with the option to restore update capability at any time.

## Automatic Backups for Plugins and Database

Every update operation is preceded by an automatic backup, ensuring you can always roll back if something goes wrong. The plugin creates ZIP archives of all plugins and themes before updating, storing them in a dedicated backup folder. Database backups are also available on demand. The system automatically cleans up orphaned backups when plugins are uninstalled, keeping your backup directory organized. Restore any previous version with a single click, with automatic reactivation if needed.

FAQ
---

1. **What is Marrison Custom Updater?**
   Marrison Custom Updater is a WordPress plugin that extends the native update system to support plugins and themes from private repositories. It allows you to distribute updates for your custom or modified plugins across multiple WordPress sites without publishing them to WordPress.org.

2. **How do I create my own private repository?**
   Create a folder on your web server and place an `index.php` file inside it. This file should return a JSON array containing the metadata for your plugins and themes. Each item in the array needs a `slug`, `version`, `name`, and `download_url` pointing to the ZIP file of the plugin. Upload your plugin ZIP files to the same folder or a subdirectory, then configure the URL in the plugin's settings.

3. **Can I use GitHub as my repository?**
   Yes, you can use GitHub Pages or any web-accessible server. The plugin makes an HTTP request to fetch the JSON index, so as long as the URL is publicly accessible, it will work. For GitHub, you can host the JSON file in a repository and use the raw.githubusercontent.com URL or GitHub Pages for the index.

4. **What happens if an update fails?**
   If an update fails, the plugin logs the error and includes it in the email report (for scheduled updates). Since every update is preceded by a backup, you can restore the previous version from the Backup section with a single click. The plugin also uses atomic file operations to prevent leaving plugins in a broken state.

5. **How do scheduled updates work?**
   Scheduled updates use WordPress's built-in cron system. Configure the frequency (daily or weekly) and email recipients in the Scheduling section. The plugin automatically checks for updates, installs them, creates backups, and sends a detailed report. You can also test the email configuration before enabling automatic updates.

6. **Can I exclude specific plugins from updates?**
   Yes, navigate to the Plugins section and click the "Exclude" button next to any plugin. Excluded plugins will not be updated by scheduled or bulk update operations. The exclusion status is clearly visible with a badge, and you can remove the exclusion at any time to restore update capability.

7. **Do backups take up a lot of disk space?**
   The plugin includes automatic cleanup of orphaned backups. When you uninstall a plugin, its backups are removed. You can also manually delete old backups from the Backup section. ZIP compression keeps file sizes reasonable, and you have full control over which backups to keep or remove.

8. **Is the plugin compatible with multisite installations?**
   Yes, Marrison Custom Updater works with WordPress multisite. You can configure the repository URL and scheduling settings from the network admin, and updates can be managed across all sites in the network. Network-activated plugins are handled correctly during updates.

9. **What are the server requirements?**
   The plugin requires WordPress 6.0 or higher and PHP 7.4 or higher. You need write access to the `wp-content` folder for backup operations, and the ZIP extension must be available on the server. For scheduled updates, WordPress cron jobs must be enabled (which is the default on most installations).

10. **Can I update the plugin itself automatically?**
    Yes, the plugin can self-update from GitHub. It checks the latest release from the official GitHub repository and shows an update notification in the WordPress plugins list. The self-update uses the same backup and rollback mechanism as other plugins, ensuring safe updates.
