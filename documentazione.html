WP Master Updater v9.2

WP Master Updater è una soluzione avanzata per la gestione degli aggiornamenti di plugin e temi privati in WordPress. Permette di collegare il tuo sito WordPress a un repository personalizzato (ospitato su un tuo server), consentendo di distribuire aggiornamenti per i tuoi prodotti proprietari con la stessa facilità di quelli ufficiali di WordPress.org.

Funzionalità Chiave:

  • Collegamento a Repository Privati (Plugin e Temi).
  • Dashboard unificata per aggiornamenti pubblici e privati.
  • Sistema di Backup automatico pre-aggiornamento con Rollback one-click.
  • Aggiornamenti automatici programmati (Giornalieri, Settimanali, Mensili).
  • Gestione centralizzata delle traduzioni.

Installazione

  1. Carica la cartella marrison-custom-updater nella directory /wp-content/plugins/ del tuo sito WordPress.
  2. Accedi al pannello di amministrazione di WordPress.
  3. Vai su Plugin e attiva WP Master Updater.
  4. Dopo l'attivazione, vedrai la voce WP Master Updater (o WPMU) nel menu laterale.

Dashboard Aggiornamenti

Accessibile dal menu WP Master Updater > Aggiornamenti.

Questa è la schermata principale dove puoi monitorare lo stato di tutti i plugin e temi installati.

Schede Statistiche

In alto trovi delle card riassuntive:

  • Plugin Privati: Numero di aggiornamenti disponibili dal tuo repo privato.
  • Plugin Pubblici: Numero di aggiornamenti dal repo ufficiale WordPress.
  • Temi Privati: Aggiornamenti disponibili per i temi proprietari.
  • Temi Pubblici: Aggiornamenti per temi standard.
  • Traduzioni: Aggiornamenti delle lingue disponibili.

Tabelle di Aggiornamento

Il plugin separa chiaramente gli aggiornamenti in diverse sezioni:

  1. Plugin Repository Privato: Lista dei tuoi plugin custom che necessitano aggiornamento.
  2. Temi Repository Privato: Lista dei tuoi temi custom da aggiornare.
  3. Repository Ufficiale WordPress: Lista standard dei plugin pubblici.

Azioni Disponibili

  • Aggiorna: Esegue l'aggiornamento del singolo elemento. Prima dell'aggiornamento viene creato automaticamente un backup.
  • Aggiorna Selezionati: (Pulsante in alto a destra nelle tabelle) Esegue l'aggiornamento massivo di tutti gli elementi selezionati tramite checkbox.
  • Aggiorna Tutti: Per i plugin ufficiali, aggiorna l'intera lista in un colpo solo.

Impostazioni

Accessibile dal menu WP Master Updater > Impostazioni. L'area è divisa in tre tab principali.

1. Tab Generale

Qui configuri il collegamento con il tuo server remoto.

  • Indirizzo Repository Plugin: Inserisci l'URL della cartella sul tuo server dove sono ospitati i plugin (es. https://tuosito.com/repo/plugins/).
  • Indirizzo Repository Temi: Inserisci l'URL per i temi (es. https://tuosito.com/repo/themes/).
  • Salva Impostazioni: Memorizza gli URL inseriti.
  • Rimuovi URL: Cancella le configurazioni e scollega il sito dal repository.

In questa pagina sono visibili anche le tabelle riassuntive dei Plugin Monitorati e Temi Monitorati, che mostrano la versione installata confrontata con quella remota.

2. Tab Programmazione

Gestisce l'automazione degli aggiornamenti.

  • Abilita Aggiornamenti Automatici: Attiva/Disattiva il cron job che cerca ed esegue gli aggiornamenti in background.
  • Frequenza: Scegli ogni quanto eseguire il controllo (Giornaliera, Settimanale, Mensile, Semestrale).
  • Invia email di test: Verifica che il sistema di notifica via email funzioni correttamente.

Guida & Download

Questa sezione (nel menu Impostazioni) è fondamentale per chi gestisce il repository lato server.

Configurazione Lato Server

Perché il plugin funzioni, devi preparare il tuo server:

  1. Crea una cartella pubblica (es. /my-repo/plugins/).
  2. Carica all'interno i file .zip dei tuoi plugin.
  3. File Index: Devi scaricare e caricare un file speciale index.php che gestisce la lettura delle versioni.

Pulsanti di Download

  • Scarica index.php per Plugin: Scarica il file da caricare nella cartella dei plugin sul server.
  • Scarica index.php per Temi: Scarica il file (specifico) da caricare nella cartella dei temi.
Importante: I file index.php per plugin e temi sono diversi e contengono logiche separate. Assicurati di usare quello corretto per ogni cartella.

Strumenti Avanzati

  • Forza controllo aggiornamenti MCU: Pulisce la cache interna di WordPress e forza una nuova verifica immediata delle versioni dal repository. Utile quando hai appena caricato un aggiornamento sul server e non vuoi aspettare il controllo automatico.

Gestione Backup

Accessibile dal menu WP Master Updater > Backup.

Ogni volta che esegui un aggiornamento tramite questo plugin, viene creato automaticamente un backup della versione precedente.

Funzionalità:

  • Lista Backup: Elenco cronologico di tutti i backup salvati (file .zip).
  • Dettagli: Mostra nome plugin/tema, versione salvata, versione attuale installata, data e dimensione.
  • Ripristina: Cliccando questo pulsante, il plugin corrente viene sovrascritto con la versione contenuta nel backup. Utile in caso di aggiornamenti che rompono il sito ("Rollback").
I backup sono salvati nella cartella /wp-content/marrison-backups/ del tuo server.

Automazione e Cron

Il plugin utilizza il sistema WP-Cron di WordPress per gestire le operazioni pianificate.

  • Controllo Aggiornamenti: Avviene automaticamente in base alla frequenza scelta.
  • Notifiche Email: Al termine di un aggiornamento automatico, viene inviata una email all'amministratore con il report dettagliato (successi, errori, versioni aggiornate).
  • Elementor: Se usi Elementor, il plugin include un trigger automatico per aggiornare il database di Elementor dopo un update, prevenendo problemi di layout.
