Ciao a tutti,

mi chiamo Angelo e lavoro con WordPress da anni, principalmente su progetti personalizzati dove spesso mi trovo a dover gestire aggiornamenti di plugin e temi "non ufficiali" su decine di siti clienti. Per questo ho creato un plugin che mi semplifica la vita e che ora do gratis a chi fa il mio stesso lavoro: **Marrison Custom Updater**.

In pratica serve a chi gestisce tanti siti WordPress e ha plugin o temi personalizzati che non vuole (o non può) caricare su WordPress.org, ma che comunque vuole distribuire e aggiornare come fossero normali plugin del repository ufficiale. Potete tenere i vostri zip su un server vostro, indicare l'URL al plugin e lui si occupa di controllare le versioni, mostrare gli aggiornamenti nella dashboard e installarli come fa WordPress di solito. L'idea è avere un unico punto da cui gestire gli aggiornamenti per tutti i siti clienti.

Cosa fa nel concreto:

- Si collega a una repo privata che ospita i vostri plugin e/o temi.
- Controlla automaticamente le versioni usando un file index.php che restituisce un JSON.
- Mostra gli aggiornamenti nella bacheca di WordPress, con notifica e badge.
- Gestisce sia plugin del repository privato che quelli pubblici di WordPress.org.
- Aggiorna anche le traduzioni, non solo plugin e temi.
- Permette aggiornamenti manuali o automatici schedulati, con email di report.
- Quando aggiornate a mano singoli plugin o temi fa un backup ZIP prima dell'operazione, con ripristino one-click.
- Quando aggiornate in automatico con lo scheduling fa anche un backup completo del database.
- Rimuove il normale sistema di aggiornamento di WordPress per evitare conflitti.
- Permette di escludere plugin specifici dal flusso di aggiornamento.
- Gestisce anche il self-update del plugin stesso.
- È multilingua: italiano e inglese sono già pronti, basta che il sito del cliente sia impostato nella lingua giusta.

Una nota importante: potete installarlo tranquillamente sui siti dei vostri clienti perché l'URL del repository viene oscurato, quindi non è visibile in chiaro nelle impostazioni.

Come si usa in due parole:

1. Create prima la vostra repo: una cartella sul vostro server con i file ZIP dei plugin e/o temi.
2. Scaricate il file index.php (uno per i plugin, uno per i temi) dalla dashboard del plugin oppure lo trovate direttamente tra i file del plugin, e caricatelo nella cartella del repository.
3. Installate il plugin sui siti che volete gestire.
4. Inserite l'URL del repository nelle impostazioni e siete a posto.

Se vi interessa lo trovate su GitHub (marrisonlab/marrison-custom-updater) e potete usarlo liberamente, senza costi. Per ora lo gestisco io nel tempo libero, quindi non aspettatevi un prodotto enterprise, ma per chi ha bisogno di un sistema semplice per gestire aggiornamenti privati su più siti può tornare utile.

Se avete dubbi o volete provarlo chiedete pure qui, rispondo appena posso.

Buon lavoro a tutti!
